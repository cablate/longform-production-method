# 既有內容編選

用於把指定期間或範圍內已有的貼文、回覆、札記、對話或其他材料編成一期。讀者可以得到多個話題、不同成熟度的思考及作者近況。完整是讓人讀懂已有內容，不要求每個議題得到完整解答。

本文件只補充編選的決策；交稿、作者回饋、後製與狀態依 [生產方法](production-method.md)。出刊週期、來源及固定欄目取自專案，不預設每位作者每週出刊。

## 先恢復來源，再選單元

1. 界定本次期間、來源與可公開範圍。取得影響理解的原文、作者回覆、提問上文、圖片／引用、日期及來源定位；跨期對話只補必要背景。
2. 以一個情境或問題及相關回覆為理解單元，再跨材料分組。保留例子、限制、未完成及更正；不要先把所有原文壓成一句摘要，再從摘要生成全文。
3. 檢查指定範圍有無漏收，再按讀者關聯、代表性與可讀性選材。完整取得不等於全部刊出，互動高低也不等於內容價值。大量來源可以分批，不能因早期找到好題目就漏掉後來的修正。

來源包要同時保留兩層：摘要、標籤與指標只負責導航；可直接寫作的原文片段、作者自回覆及必要對話鏈才負責正文。Writer 不得只拿分析摘要或支持範圍起稿。若來源中已有第一人稱、場景、吐槽、猶豫或明確力道，先判斷它們承擔什麼意思，再做編排；不能因為摘要較安全，就把作者從文章裡刪掉。

來源缺漏應定位缺少什麼；不能推論作者沒有創作，也不請作者重新講已存在的內容。原始資料仍在原處維護，本期保存定位與必要快照，不另建全量副本或要求作者每天加標籤。

## 編輯能做什麼

| 操作 | 可做 | 需要避免 |
|---|---|---|
| 選材、去重 | 保留有代表性且可讀的內容，移除重複 | 只挑支持預設結論的片段，隱去反例與更正 |
| 分組、排序 | 依情境、問題、時間或對話關係安排 | 暗示來源未成立的因果、進步或立場轉變 |
| 合併、銜接 | 接上同一情境的補充，說清楚指涉與必要背景 | 把不同情境的判斷合成普遍方法或新立場 |
| 標題、開場 | 準確介紹實際收錄的內容 | 承諾原文沒有的方法、比較、解答或成果 |
| 結尾 | 停在原有結論、觀察或疑問 | 補出作者的新理由、人生啟示、行動或未來承諾 |

最小改寫不只看改了幾個字。即使原句沒動，標題、省略或排序仍可能改變整體意思。例如來源分別記錄兩次使用不同工具的經驗，不能只憑先後次序編成「因此我改用另一個工具」。

保留原有語氣與具體細節，必要時澄清相對時間；玩笑、吐槽及對特定人的回答要帶回足夠語境。多話題可以是數則札記、問答或混合編排，不強造單一主張，也不強迫各單元彼此有因果。

週報的單元不是「一題一段摘要」。每個入選單元至少要讓沒看過原貼文的人得到一個可辨認的情境、作者當時的判斷或張力，以及必要的限制或用途；來源本來就短時可以短，來源有足夠場景與推進時不可只留下結論。整期可以有一條很輕的編選主線，但不得把五個各自成立的題目硬熔成一篇論說文。

## 缺口如何處理

| 缺口 | 下一步 |
|---|---|
| 缺上文、指涉、圖片或必要事實 | 回查來源；仍缺且影響必要內容時才問具體問題 |
| 原文沒有理由、例子或下一步 | 保留未完成，或縮小／移除單元；不追加深文訪談 |
| 原文看似矛盾 | 核對時間與情境，保留可支持的差別；不能替作者宣布改變想法 |
| 已有作者更正 | 編入更正關係，不只選較好看的舊說法 |
| 編輯發現新的疑似錯誤 | 定位問題及影響；必要時向作者確認，不冒充作者當時已更正 |
| 作者主動新增現在的想法 | 區分後來補充；若要展開新論述，說明路線改變，不悄悄把整期升為深文 |

移除缺口只有在剩餘內容仍完成本期任務時才成立；若缺口承擔核心意思，保持待確認。可以記錄另篇深入的線索，但不因此啟動新稿或拖住已完整的編選。

## 完成檢查

- 沒讀過來源的人能理解各入選單元的情境、說法及限制。
- 原句及整體編排均有來源支持，能分清作者、他人觀點與後來補充。
- 保留足夠細節與作者表達，不只是原文連結或一句式摘要，也沒有替作者加深結論。
- 標題承諾與實際收錄一致，來源缺漏及關鍵待決內容誠實標示。
- 需要引用另一篇時，在本期仍交代必要背景；除明確系列安排外，讀者不必先讀、等待或點開另一篇才能完成本期閱讀。

取得、來源還原、編選、最小改寫及整體意思核對由 AI 先完成。作者做最後接受判斷；初期完整閱讀是驗證的一部分，不能預先承諾只需看幾句或固定幾分鐘。
