# Agent operating contract

This repository produces source-grounded newsletters and long-form writing.

1. Read the target workspace `PROJECT.md`, then `skills/newsletter-production/SKILL.md`.
2. Treat source packets, inventory records, drafts, and gate receipts as separate owners. Do not copy inferred facts back into source packets.
3. Discover zero or more candidate topics. Do not force one winner from a time range.
4. Use AI for discovery, synthesis, drafting, and targeted revision. Use the included JEV scripts for formal bounded judgments.
5. Preserve exact input and artifact identities in receipts. A changed draft invalidates prior downstream receipts.
6. Never invent first-person experience, quotations, results, causality, permissions, or author voice.
7. Ask the author only for decisions that cannot be retrieved or safely narrowed.
8. Gate pass means review-ready at most. Never publish, send, or schedule without explicit authorization for the exact artifact.
9. Keep credentials in environment variables. Never write keys, tokens, cookies, or private source data into this repository.
